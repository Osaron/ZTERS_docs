# ZTERS_docs

Central repository for ZTERS documentation — user guides, SOPs, policies, workshop materials, and onboarding docs.

## Structure

Documents are organized by **year**, then by **application/topic**:

```
2025/
├── BSA Templates/          # POLICY, SOP, UGU templates
├── Hub - Accounting/
└── Onboarding Documentation/  # Payments, ClickUp, HubStaff, Wise, invoicing

2026/
├── BSA/
├── CUBE/                   # User guide, UI block matrix, Laravel upgrade,
│                           #   sync strategy, Phases 2-4 user stories & workshops
├── HUB/                    # Call Wizard Process, pricing calc, invoicing
├── ZSIGHT/                 # ZSight User Guide
├── Confluence/
├── Templates/              # Current POLICY, SOP, UGU templates
└── UpdatedPolicies/

Legal Documents/
```

## Recent focus (as of Jul 2026)

- **CUBE**: User guide kept current through Phase 4; UI block matrix and workshop user stories (Days 1-4).
- **ZSight**: User guide actively updated (latest revision Jul 19).
- **HUB**: Call Wizard Process documentation and dev review notes.
- **Templates & Policies**: Official POLICY/SOP/UGU templates finalized; CI/CD hardening, secrets management, and SSH root access policies added.
